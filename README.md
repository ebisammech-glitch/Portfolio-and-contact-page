# Portfolio-and-contact-page
This project is a simple personal portfolio and contact page created using basic HTML and CSS. It showcases personal information, skills, and contact details with a clean and user-friendly design.

Features
Simple and clean user interface
Personal portfolio section
Contact information section
Basic styling using CSS
Responsive and easy-to-navigate layout
Technologies Used
HTML5
CSS3
Purpose
This project was created to practice the fundamentals of HTML and CSS and to develop basic web design skills.

How to Run
Clone or download this repository.
Open the project folder.
Open the index.html file in your web browser.
